This repository is created as a personal JavaScript learning and reference resource.

* JavaScript
* HTML
* DOM API

## ▶️ How to Run

### JavaScript Files

Most JavaScript files can be executed using Node.js:

```bash
node filename.js
```

Example:

```bash
node Basics/javascript_basics.js
```

### DOM & Events

The `DOM` and `Events` examples require a browser.

Open the corresponding `index.html` file in a web browser to run them.

## 📌 Note

Some examples require a modern JavaScript environment because they use ES6+ features and modern APIs.
